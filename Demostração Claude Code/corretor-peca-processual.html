Corretor de Peça Processual

Cole uma peça (ou use um exemplo), ajuste os critérios de correção e receba um comentário avaliativo gerado diretamente pela API da Anthropic.

Peça a corrigir

Peças de exemplo são fictícias, feitas só para fins didáticos, e contêm pontos a melhorar de propósito.

Parâmetros de correção

de 0 a 10

Chave de API da Anthropic

Aviso de segurança: esta aplicação chama a API da Anthropic diretamente do navegador. Sua chave fica salva apenas neste navegador (armazenamento local) e é enviada diretamente aos servidores da Anthropic — nunca é enviada a nenhum outro servidor, mas fica visível no código-fonte/rede do seu navegador enquanto a página está aberta. Use apenas em computador pessoal e de confiança, nunca em máquina compartilhada, e não use uma chave de produção.

Resultado da correção

Corretor de Peça Processual — ferramenta de apoio docente. A nota sugerida é apenas isso: uma sugestão. A decisão final é sempre do professor.
