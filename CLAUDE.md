## Regra de sincronização com o git

Esta pasta deve sempre espelhar o repositório remoto (`origin/main`). Sempre que
alterações forem feitas aqui durante uma sessão — criação, edição ou remoção de
arquivos —, faça commit e `git push` para `origin/main` ao final do trabalho,
sem precisar pedir confirmação a cada vez. Isso vale tanto para mudanças feitas
pelo Claude quanto para mudanças que a usuária já tenha feito manualmente na
pasta antes da sessão (rode `git status` no início para checar se há algo
pendente de commit).

Essa autorização cobre apenas commit + push normais para `main`. Operações
destrutivas ou que reescrevem histórico (force-push, reset --hard, exclusão de
branches, amend de commits já enviados) continuam exigindo confirmação
explícita antes de executar.
